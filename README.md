# AI 영상으로 만드는 쇼츠와 유튜브

텍스트 한 줄로 시작하는 1인 영상 제작 실전서. Sora, Veo, Runway, Kling 같은 영상 생성 AI로 쇼츠와 틱톡, 릴스에 올릴 영상을 기획부터 제작, 업로드까지 혼자서 해내는 방법을 다룬다.

## 구성

- Part 1. AI 영상 시대 이해하기 — AI 영상의 원리, 대표 도구 비교, 시작 전 준비
- Part 2. 프롬프트로 영상 만들기 — 텍스트-투-비디오와 이미지-투-비디오, 프롬프트 작성법, 캐릭터 일관성
- Part 3. 클립을 이어 붙이는 실무 — 10초 클립 워크플로우, 내레이션과 자막, 배경음악과 저작권, 편집과 내보내기
- Part 4. 숏폼 플랫폼 전략 — 틱톡·쇼츠·릴스 규격, 업로드 전략과 수익화, 훅·전개·반전 기획, AI 드라마 시리즈
- Part 5. 고급 기법과 주의점 — 립싱크와 카메라 컨트롤, 실패 해결책, 윤리와 안전
- 실전 프로젝트 — AI 드라마 파일럿 1편 제작
- 확인 문제와 해설, 마무리
